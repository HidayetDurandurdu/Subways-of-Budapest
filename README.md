## 📌 Project Overview

This project is a browser-based web game inspired by the Budapest metro system. The application allows users to register, log in, play an interactive game, and compete for high scores. It was developed as part of a university web programming assignment, with a focus on front-end development, game logic, and user interaction.

The project demonstrates the implementation of a complete client-side application, including authentication flows, game mechanics, scoring logic, and a structured user interface.

---

## 🎮 Game Concept

Players interact with a metro-themed game where gameplay logic, scoring, and progression are handled dynamically in the browser. The application tracks player scores and displays a high-score leaderboard, encouraging replayability and competition.

---

## 🧠 Key Features

- User authentication (registration and login)
- Interactive game logic implemented in JavaScript
- Score calculation and tracking
- High-score leaderboard
- Menu system with settings and notifications
- Responsive UI styled with SCSS and CSS
- Modular JavaScript structure for maintainability

---

## 🏗️ Technical Implementation

### Frontend
- **HTML5** for structure
- **CSS / SCSS** for styling and layout
- **JavaScript (ES6)** for:
  - Game logic
  - User authentication handling
  - Menu navigation
  - Score calculation and persistence
  - High-score management

### Architecture
- Modular folder structure separating:
  - Game logic
  - Menu and authentication logic
  - High-score handling
- Clear separation between UI behavior and game mechanics

---

## 📁 Project Structure

- `index.html` – main entry point
- `css/` – styles written in SCSS and compiled to CSS
- `js/`
  - `Game/` – core game logic and scoring
  - `Menu/` – login, registration, menu handling
  - `Highscores/` – leaderboard functionality
- `data/` – game-related data and configuration files
