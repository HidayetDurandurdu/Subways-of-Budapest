Game Rules

Objective

Build four metro lines across Budapest to earn the highest score possible.

How to Play

  1. Draw station cards (A, B, C, D, or Joker)
  2. Build metro line segments connecting stations
  3. Each line must start from its designated starting station
  4. Complete 4 rounds (one for each metro line: M1, M2, M3, M4)

Building Rules

  • Click on a station to build a segment from your current line's endpoint
  • Segments can be horizontal, vertical, or diagonal (45°)
  • Match the card letter (A/B/C/D) or use a Joker
  • Cannot create loops or intersect existing segments
  • Cannot skip over other stations
  • Station ID 30 (Deák tér) acts as a universal Joker station

Scoring

  • Districts: Number of districts covered × Max stations in one district
  • Danube Crossings: Bonus points for crossing the river
  • Railway Stations: Points for connecting train stations
  • Junctions: Bonus for connecting multiple metro lines at one station

Round End

After drawing 8 cards, the round ends and a new metro line begins. The game ends after completing all 4 rounds.
